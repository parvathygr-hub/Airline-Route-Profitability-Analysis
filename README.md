
# Airline Route Profitability and Revenue Optimization System

## Project Overview
This project analyzes airline operational and financial data using Power BI to identify profitable routes, understand revenue patterns, evaluate operating costs, and support data-driven business decisions.

## Objectives
- Analyze airline revenue and profitability.
- Identify profitable and loss-making routes.
- Evaluate passenger load factor.
- Compare operating costs across routes.
- Analyze seasonal demand and aircraft performance.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- Python
- Pandas
- NumPy

## Dashboard Pages
1. Executive Overview
2. Route Performance Analysis
3. Revenue Analysis
4. Cost Analysis
5. Profitability Analysis

## Data Processing
Python (Pandas and NumPy) was used for data cleaning and preprocessing. Power Query was used for additional data transformation.

## Key Learnings
- Data cleaning and preprocessing
- Data modeling
- DAX calculations
- Interactive dashboard development
- Business insight generation
